# Search on Youtube

Search for selected text directly on YouTube: use the context menu to search YouTube for any text selected from a web page.

---

## Installation

1. Download the extension from your browser's extension catalog.
2. Enable the extension in your browser settings.
3. Select text on any page
4. Right-click to open the context menu
5. Click on "Search on YouTube"

---

## Privacy Policy

No personal data is collected, shared, or sent. All information remains on your device.
